How to Use Your .ICO File

🌐 Web Favicon Integration

Place favicon.ico into your website's root folder or assets directory and include it inside your HTML <head>:

<link rel="icon" type="image/x-icon" href="/favicon.ico">

🪟 Windows Applications & Shortcuts

Windows displays icons in Explorer, Desktop, and Taskbar. Right click any shortcut → Properties → Change Icon → choose your generated .ico.

Also perfect for Electron (icon: 'app.ico'), Tauri, C# WPF, and PyInstaller.

💡 Why Multi-Resolution ICO?

A single .ico file holds multiple image layers. Windows and browsers automatically pick the sharpest native resolution for each display scale, preventing fuzzy downsampling artifacts.
